# Superstore Sales (Power BI)

This repository contains a Power BI report built on a “Superstore” sales dataset, plus a PDF export for easy viewing/sharing.

## Files

- **`Superstore Sales Dataset.pbix`**: The interactive Power BI report (open in Power BI Desktop).
- **`Superstore Sales Dataset.pdf`**: A static export of the report (quick preview without Power BI).

## Requirements

- **Power BI Desktop (Windows)** to open and interact with the `.pbix` file.

## How to use

### View the report (no Power BI)

Open `Superstore Sales Dataset.pdf`.

### Open the interactive report (Power BI Desktop)

1. Install Power BI Desktop.
2. Open `Superstore Sales Dataset.pbix`.
3. If Power BI prompts for missing data sources, update the data source settings and refresh.

## Notes

- This repo currently ships the **report** (`.pbix`) and a **PDF export**. If you intend to include the raw dataset files (CSV/Excel), add them under a `data/` folder and update this README with the exact file names and refresh steps.
