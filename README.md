## 📌 Project Overview

The **Superstore Sales Analytics Dashboard** is a Power BI business intelligence project built using the Superstore sales dataset.

The project transforms transactional sales data into an interactive reporting solution that can be used to understand **sales performance, profitability, product trends, customer segments, and regional performance**.

It demonstrates practical experience with **Power BI, data preparation, data modeling, KPI development, interactive visualizations, and business-focused reporting**.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify high-performing products and categories.
- Understand customer and segment-level performance.
- Compare sales across regions and geographical markets.
- Evaluate profitability and identify areas of improvement.
- Present business information through an interactive Power BI dashboard.

## 🚀 How to Use

### View the dashboard without Power BI

Open **`Superstore Sales Dataset.pdf`** to review the report as a static document.

### Open the interactive Power BI report

1. Install **Power BI Desktop** on Windows.
2. Open **`Superstore Sales Dataset.pbix`**.
3. Review the report pages and interact with the available filters and visuals.
4. If Power BI requests a data-source update, configure the appropriate source settings and refresh the data.
